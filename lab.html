Security & investigative tooling

Understand the system.
Follow the evidence.

Forensic, endpoint, and security tool experience supports scoped technical work. Each engagement starts with an authorized question and a clear boundary.

Forensic examination

Example question: What system or file activity can the available artifacts help reconstruct? Define the evidence available, examine relevant artifacts, and explain the limits of the findings.

EnCase · FTK · Autopsy · Volatility · Velociraptor

Endpoint & binary inspection

Example question: What is running, what is it doing, and which observations support further investigation? Apply endpoint inspection, alternate boot environments, and binary-identification tooling as appropriate.

Sysinternals · Process Monitor · Windows PE · Detect It Easy · Kali live boot · Hiren’s BootCD

Credential security

Example question: What can authorized testing reveal about password exposure? Credential collection, recovery attempts, and password testing are distinct activities, each requiring an agreed scope.

Hashcat · Hydra · Nmap · Metasploit · DIRB · Responder · Ettercap

These questions illustrate possible engagement scopes. They are not descriptions of completed client cases.
